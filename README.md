# Redacta AI

Redacta AI is a privacy-focused AI project that aims to detect sensitive information in documents and images and help users remove it before sharing.

The main idea is to keep the analysis on the user's device instead of sending private content to a cloud service.

## Current Status

🚧 Work in progress.

The project is currently being built for the Snapdragon AI Lab Build & Present Challenge.

## Planned

* Detect sensitive information in documents
* Analyze images and screenshots
* Show what information was detected
* Allow users to redact selected information
* Run AI models locally
* Explore Snapdragon NPU optimization and benchmarking
